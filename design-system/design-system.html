01 · Brand

Logo and voice

The Healthray logo (red heart, blue wordmark) is used as supplied: shown 52px tall, the white version on dark surfaces. Name comes from config, never typed into pages.

Tone

Write for a sceptical owner-pharmacist. Counter words: strip, batch, scheme, udhaar. Value as loss avoided. Sentence case. No hype, no fake numbers.

08 · Rules

Do and don't

Do

  • Use tokens from :root only.
  • Use ruled lines, real tables and plain numbers.
  • Label every sample number and screen.
  • Name the plan when a feature is plan-gated.
  • Keep focus rings and 4.5:1 text contrast.
  • Respect reduced motion.

Don't

  • Add pills or decorative capsules.
  • Load any second webfont.
  • Use emoji or icon fonts.
  • Rotate or tilt screenshots.
  • Show status by colour alone.
  • Invent counts, ratings or testimonials.

Icons and motion

Inline SVG sprite only, one stroke weight, decorative icons hidden from assistive tech. Motion is brief and optional. The only playful details: the eyebrow marker and the estimator slider thumbs.
