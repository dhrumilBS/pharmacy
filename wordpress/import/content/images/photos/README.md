# Inner pictures for the multi-branch article

Five real photographs from Pexels (free licence: commercial use, no attribution needed, editing allowed). Each was cropped to
2:1, resized to 1600 x 800 and saved as WebP at 50-80 KB. The photos show real people and one real street; captions stay neutral
and do not present them as our staff or customers.

`renders/` holds the earlier 3D renders (made with `wordpress/tools/scene3d/`) and the folder above holds the first illustrations
(`inner-*.png`); they are only used when a spot has no file here. A photo with the same file name (JPG, WebP or PNG) replaces the
one in use. Publish with `D:\xampp\php\php.exe wordpress\import\blog-multi-branch.php`.
